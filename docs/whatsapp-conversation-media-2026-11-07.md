## Behavior

Conversation bubbles show the existing date/time format on consecutive messages from the same sender. Photos and videos use the larger media card with any caption below the attachment. Single photos keep their original aspect ratio, and album tiles keep access to the gallery. Stickers stay separate from photo albums. The conversation composer uses a 16 px currentColor Pix SVG with the same slate styling as its neighboring controls.

The inline and expanded video use the same controls for playback, seeking and elapsed/total time. The speed control cycles the available rates. Hover or keyboard focus over the speaker exposes a vertical slider. Clicking the speaker toggles mute and restores the prior level. Expanding the video pauses inline playback.

## WhatsApp identity

On principal, an operator could initiate a conversation using a Brazilian mobile number with nine digits while the provider sent incoming events using the old eight-digit form. The provider returned the same account identity for each reported pair. Separate contact inboxes were storing the agent's outgoing messages and the recipient's reply in different open conversations.

Only candidates generated by the existing Brazilian mobile normalizer with an open conversation in the same inbox are eligible. The registration lookup for the alternate must agree with the verified peer identity. With no verified peer LID, both registration lookups must match. Unregistered, mismatched and unavailable lookups cannot authorize a merge. Existing resolved conversations and WhatsApp groups are outside this path. The authenticated webhook and normal direct-conversation builder serialize on the inbox. For a verified pair the original open display ID is retained, anchored to the confirmed contact inbox. The existing merge service preserves messages, labels, participants, mentions and MarcoXIA pause priority.
