# MarcoXIA panels, navigation and manual attendance — November 1, 2026

Marco requested neutral panels matching Attendance, matching prompt typography, larger editors, consistent transcription/voice field spacing, compact clickable agent cards and a manual-attendance switch reflecting actual contacts.

AgentSection and the voice/overview panels use the existing neutral solid-1 surface. Fields retain a contrasting input surface. System and execution prompts share the inherited Inter stack, 14 px text and 24 px lines; both open at a minimum of 448 px. Short instruction editors open at 192–208 px and remain vertically resizable. Explicit minimum heights are necessary because the application stylesheet otherwise overrides textarea rows with a 64 px height. Voice selectors have the same margin as saved connections, and voice ID/model controls align at 40 px. API key fields remain compact and unchanged in purpose.

The card body opens configuration; its buttons keep their own actions and keyboard access. The redundant general-support status row is removed. The existing general switch keeps its accessible name. The pending-reply shortcut displays only its chat icon, with its full name/count available to assistive technology and as a title. The manual label/count opens manual-only attendance, and the separate two-state switch pauses/resumes the group. The synthetic card measured 232 px high at desktop and 390 px viewports; its height is content-driven.

Returning through the sidebar URL clears the selected editor and shows all agents. The route update guard preserves genuine unsaved changes. The editor reports its dirty state against its normalized saved form, instead of comparing JSON property order against the serialized profile. External navigation to manual attendance retains the manual filter; section synchronization avoids overwriting the query that initiated it.

The previous switch used only manual_sessions_enabled, but an explicit per-contact resume can override a suspended group. The previous count also included historical selections. The API now reports active eligible manual states and resumable group-paused/legacy selections. Connection-health polling refreshes these counts every ten seconds without replacing an open editor draft.

PATCH /assistants/:id/manual_sessions accepts a strict JSON boolean under the existing administrator/account checks. It pauses active manual members, invalidates pending execution tokens and clears individual overrides even when the saved group flag was already false. Resume restores only group pauses and legacy suspended selections, retaining individual/human pauses and closed/blocked contacts. General support is not switched on or off. Manual-only coverage is available even with general automatic coverage on. State changes and the flag update are transactional; existing assistant configuration-change cancellation rules remain in force. No database migration is needed.
